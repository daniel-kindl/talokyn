# Identity and direction

## Product truth

Talokyn is planned cross-platform orchestration infrastructure for coding agents. Its proposed capabilities include persistent sessions, supervision, handoffs and policy checks.

The brand must not present planned features as shipping behavior.

## Personality

| Character | Expression |
| --- | --- |
| Dependable | Consistent geometry, predictable layout and calm language |
| Protective | Guardian-shaped negative space and bounded visual forms |
| Independent | No provider logo as part of the primary mark |
| Technical | Clear labels, measured spacing and precise terminology |
| Restrained | Dark ink surfaces with one cool accent and minimal brass |

## Concept

The guardian is **architectural**, not a character illustration. Two facets enclose a central vertical element. A restrained chevron serves as the crest.

This structure suggests oversight and organized delegation. It avoids explicit eyes, swords, armor or a human face.

The composition works without gradients or a background. It must remain legible in one color.

## Visual principles

1. Prefer flat surfaces over gradients and photographic texture.
2. Use asymmetry only when it clarifies hierarchy.
3. Give type generous margins and restrained letter spacing.
4. Allow the mark to hold visual attention.
5. Keep data visualizations truthful and limited to the actual content.
6. Preserve high contrast in documentation and terminals.
7. Never rely on color alone to signal a session state.

## Application hierarchy

A developer should recognize Talokyn from the mark, then read the product name. Finally, they should understand the task from the content.

A banner may contain the mark, name and one short explanation. The CLI should show the name sparingly.

The documentation should favor readable content over large decorative mastheads.

## Avoid

- Neon blue and orange combinations.
- Science-fiction fonts, pseudo-Greek lettering and bevelled chrome.
- Mythological statuary as the primary logo.
- Generic bot heads, brains, glowing circuitry and stock AI illustrations.
- Huge blurred shadows, heavy glass effects and repeated gradients.
- Fake dashboards with fabricated production statistics.

Editorial visuals may reference Greek stone or architecture subtly. They are not a substitute for the primary logo.
