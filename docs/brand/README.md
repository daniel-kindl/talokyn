# Talokyn visual identity

**Status: proposed for owner review.** This identity defines a dark-first direction for Talokyn. It does not imply a working application.

![Guardian mark](../../assets/brand/logo/icon-dark.svg)

Talokyn communicates dependable supervision of independent coding agents. The abstract guardian is the central symbol. Typography, spacing and system diagrams remain quiet.

## Direction in one sentence

A quiet guardian symbol for reliable, transparent control of delegated agent work.

## What is deliberately absent

No neon glow, 3D armor, photorealistic character, generic AI brain or animated gradients. Those choices make this infrastructure brand less credible and less reusable.

No external image services or paid font assets are required to reproduce the supplied SVGs.
