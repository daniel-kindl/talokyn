# Logo system

The brandmark is a compact guardian abstraction. It reads as a protective crest, two side facets and a central vertical element.

## Construction

| Property | Specification |
| --- | --- |
| Source grid | 128 by 128 units |
| Main material | One flat solid color |
| Optional detail | One small brass diamond |
| Optical center | Main body centered at x=64 |
| Geometry | Mirrored facets, chevron crown, vertical center |
| File format | Native SVG with a viewBox |
| Animation | None in the primary identity |

The diamond is optional. Use the compact mark without it at small sizes.

The brandmark is not a literal helmet. Do not add facial features or armor details.

## Clearspace

Use one-quarter of the mark's width around each side. No text, badge, icon or crop may enter this space.

For a 128-unit mark, leave at least 32 units of clearspace.

The icon background is part of the square app-icon variant. Clearspace is measured from the symbol, not the tile edge.

## Minimum sizes

| Use | Minimum |
| --- | --- |
| Compact icon in digital UI | 24 CSS px |
| Detailed brandmark | 40 CSS px |
| Horizontal lockup | 220 CSS px wide |
| Printed standalone mark | 8 mm wide |
| Full stack with subtitle | 300 CSS px wide |

At 16 CSS px, use a simplified compact glyph after explicit raster review. Do not scale the detailed mark without checking its negative spaces.

## Wordmark

The wordmark uses Inter SemiBold and deliberate tracking. All letters are uppercase in brand lockups.

For product prose, write **Talokyn**, not TALOKYN. Use normal title casing outside the logo.

SVG lockups use a live text element with fallback fonts. For consistent print output, convert final approved text to paths.

Do not bundle, upload or redistribute the source font files.

## Variants and backgrounds

Dark surfaces use off-white geometry and an optional brass detail. Light surfaces use ink geometry and a darker brass detail.

One-color printing uses no brass. Avoid direct placement on photographs unless a solid backing panel provides sufficient contrast.

## Incorrect use

- Do not rotate, skew, outline or stretch the mark.
- Do not recolor facets independently.
- Do not replace the central stem with another company's logo.
- Do not apply gradients, glows, shadows or 3D extrusion.
- Do not put the mark inside a second shield.
- Do not use a complex illustrated guardian as the application icon.
