# Security policy

Talokyn is pre-release, design-only infrastructure. **No tested security boundary exists yet.**

Report vulnerabilities using GitHub's private vulnerability reporting for this repository if available. Otherwise contact the repository owner privately rather than opening a public issue with exploit details.

Do not include credentials, full prompts, private transcripts or tokens in issues, logs or reproductions. Session scope and control leases do not authenticate separate agents running under the same OS identity. Git worktrees do not provide security isolation.

See the [security/performance audit](docs/design/PERFORMANCE_SECURITY_AUDIT.md) and [red-team report](docs/design/RED_TEAM_REPORT.md) for unresolved threats.
